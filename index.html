Como Gravar na Tag NFC

1 Edite seus dados e Baixe o arquivo HTML

Após editar seus dados aqui no cartão, clique no botão abaixo para baixar o código atualizado do seu cartão de visita em um arquivo único index.html.

2 Hospede seu arquivo na Internet (Gratuito)

Para funcionar no NFC de qualquer celular, seu cartão precisa estar num link de internet (https://...).

  • Envie o arquivo para o Vercel, Netlify ou GitHub Pages.
  • Ou coloque o arquivo no seu servidor de hospedagem próprio (WordPress/cPanel).

3 Grave na sua Tag NFC com o App Celular

  1. Baixe o app NFC Tools (grátis na Play Store / App Store).
  2. Abra o app e vá na opção Escrever (Write).
  3. Clique em Adicionar um registro (Add a record).
  4. Selecione a opção URL / Link Web.
  5. Cole o link do seu cartão publicado (ex: https://seunome.vercel.app).
  6. Clique em Escrever (Write) e encoste seu cartão/tag NFC na traseira do celular!
